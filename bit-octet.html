1. Qu'est-ce qu'une information numérique ?

Une information numérique est une information représentée et traitée par un ordinateur sous une forme compréhensible par la machine.

Un ordinateur peut traiter plusieurs types d'informations :

  • 📝 Texte
  • 🔢 Nombres
  • 🖼️ Images
  • 🎵 Sons
  • 🎬 Vidéos
  • 📄 Documents
À retenir :
Pour être traitée par un ordinateur, l'information est finalement représentée sous forme numérique, notamment avec les valeurs 0 et 1.

2. Le système binaire

Les ordinateurs utilisent principalement le système binaire. Contrairement au système décimal que nous utilisons quotidiennement, le système binaire utilise seulement deux chiffres :

0 1

Le chiffre 0 et le chiffre 1 permettent de représenter les informations numériques.

Exemple :
Le nombre décimal 5 s'écrit 101 en binaire.

Pourquoi 0 et 1 ?

Les circuits électroniques d'un ordinateur peuvent avoir deux états principaux : un état représenté par 0 et un autre représenté par 1.

3. Le bit

Le mot bit vient de l'expression anglaise Binary Digit.

C'est la plus petite unité d'information numérique. Un bit peut prendre seulement deux valeurs :

0 1
Définition :
Un bit est une unité d'information qui peut avoir la valeur 0 ou 1.

Exemple

Une suite de 8 bits peut être :

1 0 1 1 0 0 1 0

Cette suite contient donc 8 bits.

4. Le nibble

Un nibble est un groupe de 4 bits.

1 nibble = 4 bits

Comme un octet contient 8 bits :

1 octet = 2 nibbles
Exemple :
1010 = 1 nibble = 4 bits

5. L'octet

Un octet est un groupe de 8 bits. En anglais, on utilise souvent le terme Byte.

1 octet = 8 bits

Exemple

Le nombre binaire suivant contient 8 chiffres :

1 0 0 1 0 1 1 0

Il représente donc 1 octet.

⚠️ Ne pas confondre bit et octet.

1 octet = 8 bits

Remarque :
Dans l'informatique moderne, les fabricants de stockage utilisent souvent les préfixes décimaux (1 kB = 1 000 octets, etc.), tandis que les unités binaires strictes utilisent KiB, MiB, GiB, TiB avec 1 024 comme facteur. Pour les exercices scolaires, on peut utiliser la convention 1 Ko = 1 024 octets si elle est demandée.

7. Les conversions

Conversion octets → bits

Nombre de bits = Nombre d'octets × 8
Exemple :
5 octets = 5 × 8 = 40 bits

Conversion bits → octets

Nombre d'octets = Nombre de bits ÷ 8
Exemple :
64 bits = 64 ÷ 8 = 8 octets

Conversion entre les grandes unités

1 Ko = 1 024 octets1 Mo = 1 024 Ko 1 Go = 1 024 Mo 1 To = 1 024 Go
Exemple :
3 Go = 3 × 1 024 = 3 072 Mo
Autre exemple :
2 To = 2 × 1 024 = 2 048 Go

10. Bit et vitesse de transmission

Le bit est également utilisé pour mesurer la vitesse de transmission des données sur un réseau.

Unité Signification
bit/s bits par seconde
Kbit/s kilobits par seconde
Mbit/s mégabits par seconde
Gbit/s gigabits par seconde
⚠️ Attention :
La vitesse Internet est généralement exprimée en bit/s, alors que la taille d'un fichier est généralement exprimée en octets.

Exemple

Une connexion de 80 Mbit/s est une vitesse de transmission.

Un fichier de 500 Mo est une taille de fichier.

11. Différence entre b et B

Symbole Signification Utilisation
b bit Transmission
B Byte / octet Taille des fichiers
Exemple :

100 Mb/s → vitesse de transmission
100 MB → taille exprimée en mégaoctets
