📄 Projet : Document professionnel Tetikasa : Taratasy ofisialy

Objectif : Créer une lettre administrative professionnelle.

Tanjona : Mamorona taratasy ofisialy matihanina.

📌 Étapes :

📌 Dingana :

  1. Ouvrir Microsoft Word
  2. Sokafy Word
  3. Écrire l’en-tête (Nom, adresse)
  4. Soraty ny mombamomba
  5. Ajouter la date
  6. Ampidiro daty
  7. Rédiger le contenu
  8. Soraty ny hafatra
  9. Ajouter signature
  10. Asio sonia

📌 Exemple :

Nom : Rakoto
Adresse : Antananarivo
Date : 12 Avril 2026

Objet : Demande de stage

Madame, Monsieur,
Je vous adresse cette lettre pour demander un stage...
