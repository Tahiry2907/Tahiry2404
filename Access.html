💾 Microsoft Access

Cours complet sur la création et la gestion des bases de données avec Microsoft Access.

1. Qu'est-ce que Microsoft Access ?

Microsoft Access est un logiciel de Microsoft spécialisé dans la création et la gestion des bases de données.

Il permet de stocker, organiser, rechercher, modifier et présenter des informations de manière structurée.

Exemples d'utilisation

  • Gestion des élèves
  • Gestion des notes
  • Gestion d'une bibliothèque
  • Gestion d'une boutique
  • Gestion des clients
  • Gestion des employés

2. Qu'est-ce qu'une base de données ?

Une base de données est un ensemble d'informations organisées afin de pouvoir les consulter et les gérer facilement.

Par exemple, un établissement scolaire peut créer une base de données pour enregistrer les informations de tous ses élèves.

Exemple

INFO_PRO_GESTION_ELEVES

Cette base peut contenir plusieurs tables :

  • Élèves
  • Classes
  • Matières
  • Notes

3. La table

Une table est l'élément principal utilisé pour stocker les données. Elle est organisée en lignes et en colonnes.

Matricule Nom Prénom Classe
E001 RAKOTO Jean 9ème
E002 RABE Marie 9ème
E003 ANDRIA Paul 8ème

4. Champ et enregistrement

Le champ

Un champ représente une catégorie d'information.

Exemple : Nom, Prénom, Classe, Téléphone.

L'enregistrement

Un enregistrement représente toutes les informations concernant un élément ou une personne.

Dans le tableau précédent, la ligne contenant E001, RAKOTO et Jean est un enregistrement.

5. Les types de données

Type Utilisation
Short Text Nom, prénom, adresse
Number Âge, quantité, note
Date/Time Date de naissance
Currency Prix, salaire
Yes/No Oui/Non
AutoNumber Numéro automatique

6. La clé primaire

La clé primaire permet d'identifier de manière unique chaque enregistrement d'une table.

Dans une table d'élèves, le Matricule peut être utilisé comme clé primaire.

Matricule Nom Prénom
E001 RAKOTO Jean
E002 RABE Marie

Deux élèves ne doivent pas avoir le même matricule.

7. Créer une base de données

  1. Ouvrir Microsoft Access.
  2. Choisir Blank Database.
  3. Donner un nom à la base de données.
  4. Exemple : Gestion_Eleves.accdb.
  5. Cliquer sur Create.

8. Créer une table Élèves

Champ Type de données
Matricule Short Text
Nom Short Text
Prénom Short Text
Sexe Short Text
DateNaissance Date/Time
Classe Short Text
Téléphone Short Text
Adresse Short Text

Le champ Matricule peut être défini comme Primary Key.

9. Les relations entre les tables

Une base de données peut contenir plusieurs tables. Les relations permettent de connecter les tables entre elles.

Exemple

Table Élèves :

Matricule — Nom — Prénom — ClasseID

Table Classes :

ClasseID — NomClasse

Le champ ClasseID peut permettre de relier les deux tables.

10. Les requêtes

Une requête permet de rechercher, filtrer, trier ou calculer des informations dans une base de données.

Exemple

Rechercher tous les élèves de la classe 9ème.

Condition :

Classe = "9ème"

11. Les formulaires

Un formulaire facilite la saisie et la consultation des données.

Exemple

Formulaire Élève :

  • Matricule
  • Nom
  • Prénom
  • Sexe
  • Date de naissance
  • Classe
  • Téléphone
  • Adresse

12. Les états / rapports

Un état permet de présenter les données dans une forme organisée, notamment pour l'impression.

Exemples

  • Liste des élèves
  • Liste des élèves par classe
  • Liste des notes
  • Résultats scolaires

13. Projet pratique — Gestion des élèves

  • Élèves de sexe féminin
  • Élèves de sexe masculin
  • Élèves ayant une note supérieure à 10
  • Élèves ayant une moyenne inférieure à 10

Formulaires

  • Formulaire Élèves
  • Formulaire Notes

États

  • Résultats des élèves

Lesona feno momba ny famoronana sy fitantanana base de données amin'ny Microsoft Access.

1. Inona ny Microsoft Access?

Microsoft Access dia logiciel an'ny Microsoft ampiasaina hamoronana, hitahirizana ary hitantanana base de données.

Afaka ampiasaina izy mba hitahirizana, hitadiavana, hanovana ary handaminana vaovao maro.

Ohatra

  • Fitantanana mpianatra
  • Fitantanana naoty
  • Fitantanana bibliothèque
  • Fitantanana magasin
  • Fitantanana clients
  • Fitantanana mpiasa

2. Inona ny Base de données?

Ny base de données dia fitambaran'ny vaovao voalamina mba ho mora tehirizina, tadiavina ary tantanana.

Ohatra, ny sekoly iray dia afaka manana base de données ahitana ny mombamomba ny mpianatra rehetra.

Ohatra amin'ny base de données:

INFO_PRO_GESTION_ELEVES

Afaka ahitana tables maromaro izy:

  • Élèves
  • Classes
  • Matières
  • Notes

3. Inona ny Table?

Ny Table dia toerana itehirizana ireo données. Mizara ho lignes sy colonnes izy.

Matricule Nom Prénom Classe
E001 RAKOTO Jean 9ème
E002 RABE Marie 9ème
E003 ANDRIA Paul 8ème

4. Champ sy Enregistrement

Champ

Ny champ dia karazana information iray.

Ohatra: Nom, Prénom, Classe, Téléphone.

Enregistrement

Ny enregistrement dia ligne iray ahitana ny information rehetra momba ny olona na zavatra iray.

Ohatra, ny ligne misy E001, RAKOTO ary Jean dia enregistrement iray.

5. Karazana données

Type Fampiasana
Short Text Anarana, fanampin'anarana, adresse
Number Isa, taona, naoty
Date/Time Daty sy ora
Currency Vola
Yes/No Eny/Tsia
AutoNumber Numéro automatique

6. Clé primaire

Ny clé primaire dia champ iray ampiasaina hamantarana manokana ny enregistrement tsirairay.

Ohatra, ny Matricule no azo atao clé primaire amin'ny table Élèves.

Tsy tokony hisy mpianatra roa manana matricule mitovy.

  4. Ohatra: Gestion_Eleves.accdb.
  5. Tsindrio Create.

Ny Query dia ampiasaina hitadiavana, hanivanana, handaminana na hikajiana données.

Ohatra

Condition:

Classe = "9ème"

Ny Report na État dia ampiasaina hanehoana sy hanontana données amin'ny endrika voalamina.

  • Liste des notes
