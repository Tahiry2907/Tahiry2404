🟩 Trimestre 2 : Excel

FR : Excel est un tableur pour calcul automatique.

ML : Excel dia programme hanaovana calcul automatique sy tableau.

📌 Cellule

Une cellule = intersection ligne/colonne

AB
1Nom
2Note

📌 Fonction SOMME ➕

Addition automatique des valeurs

=SOMME(B2:B5)

📊 Exemple :

NomNote
Jean10
Paul12
Marie14
Total=SOMME(B2:B4)

ML : SOMME dia manampy isa rehetra.

📌 Fonction SOMME.SI 🎯

Addition avec condition

=SOMME.SI(B2:B5;">=10")

📊 Exemple :

NomNote
Jean8
Paul12
Marie15
Total ≥10=SOMME.SI(B2:B4;">=10")

ML : SOMME.SI dia manampy isa raha mahafeno condition.

📌 Fonction SI (IMPORTANT) 🤔

La fonction SI permet de tester une condition :

=SI(B2>=10;"Admis";"Ajourné")

📊 Exemple :

NomNoteRésultat
Jean8=SI(B2>=10;"Ajourné";"Admis")
Paul12=SI(B3>=10;"Admis";"Ajourné")
Marie15=SI(B4>=10;"Admis";"Ajourné")

ML : SI dia manamarina raha marina na diso ny condition (ohatra: afaka na tsy afaka).

🧪 Devoir

  • Créer tableau notes élèves 📊
  • Calcul total avec SOMME ➕
  • Condition avec SI 🤔

📝 Évaluation

Exercice Excel : tableau + SOMME + SOMME.SI + SI
