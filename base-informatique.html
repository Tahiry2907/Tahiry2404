🟢 Trimestre 1 : Bases Informatique

⚙️ Composants de l’ordinateur (Avec fonctions)

🧠 CPU Central Processing Unit = Processeur (Cerveau de l’ordinateur) ➡ Exécute les instructions et traite les données
⚡ RAM Random Access Memory = Mémoire vive ➡ Stockage temporaire des données en cours d’utilisation
💾 HDD / SSD Hard Disk Drive / Solid State Drive = Stockage ➡ Stocke les fichiers, logiciels et données
🔩 Carte mère Motherboard = Plateforme principale ➡ Connecte tous les composants ensemble
🔌 Alimentation Power Supply Unit (PSU) ➡ Fournit l’électricité à l’ordinateur

🧠 Rappel fonctionnement

  • Entrée → clavier / souris
  • Traitement → CPU
  • Stockage → RAM / disque
  • Sortie → écran / imprimante

📌 Résumé

L’ordinateur fonctionne grâce à plusieurs composants qui travaillent ensemble : traitement, stockage et affichage.
