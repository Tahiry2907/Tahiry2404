🧠 Algorithmique - Logique de programmation

📘 Définition

L’algorithmique est une méthode pour résoudre un problème étape par étape.

Algorithmique dia fomba fandaminana dingana hanatanterahana asa iray.

🧠 C’est quoi un algorithme ?

✔ Suite d’instructions logiques
✔ Résolution de problème
✔ Utilisé en programmation

⚙️ Structure SI / SINON

SI condition est vraie, alors on exécute une action, SINON on exécute une autre.

RAHA marina ny condition dia atao action iray, raha tsy izany dia action hafa.

SI condition ALORS
  Action 1
SINON
  Action 2
FIN SI

📊 Exemple simple

SI âge >= 18 ALORS
  Afficher "Majeur"
SINON
  Afficher "Mineur"
FIN SI

🧠 Pseudo-code

Le pseudo-code est une façon d’écrire un algorithme sans langage de programmation.

Début
Lire âge
SI âge >= 18 ALORS
  Afficher "Adulte"
SINON
  Afficher "Enfant"
Fin SI
Fin

🧪 Activité

  • Écrire un algorithme pour vérifier si un nombre est positif
  • Créer un pseudo-code pour un test de note

Algorithmique = logique + étapes + conditions (SI / SINON).
