⚠️ Précautions importantes

  • Si BitLocker demande une clé de récupération, arrêtez-vous et recherchez cette clé avant de continuer.

1. Qu'est-ce que le BIOS / UEFI ?

Le BIOS ou l'UEFI est un micrologiciel qui initialise certains composants et aide l'ordinateur à démarrer.

  • BIOS / UEFI : configuration de l'ordinateur.
  • Boot Menu : choisir temporairement le périphérique de démarrage.
  • Boot Order : ordre de recherche des périphériques de démarrage.

Conseil : le Boot Menu est généralement préférable pour démarrer une seule fois sur une clé USB, sans modifier durablement l'ordre de démarrage.

2. Touches BIOS et Boot Menu par marque

Recherchez la marque de votre ordinateur.

💻

HP

Ordinateurs portables et de bureau HP.

  • BIOS : F10
  • Boot Menu : Échap (Esc), puis F9 sur de nombreux modèles
Étapes
  1. Éteignez complètement le PC.
  2. Allumez-le et appuyez plusieurs fois sur Échap.
  3. Choisissez F9 pour le menu de démarrage ou F10 pour la configuration du BIOS.
🖥️

Dell

PC Dell de bureau ou portable.

  • BIOS : F2
  • Boot Menu : F12
Étapes
  1. Allumez le PC ou redémarrez-le.
  2. Appuyez plusieurs fois sur F12 pour choisir le périphérique de démarrage.
  3. Utilisez F2 pour accéder aux réglages du BIOS.
💻

Lenovo

ThinkPad, IdeaPad et autres modèles.

  • BIOS : F1 ou F2
  • Boot Menu : F12 sur de nombreux modèles
Étapes
  1. Vérifiez la touche indiquée pour votre modèle.
  2. Certains modèles possèdent un bouton Novo dédié.
  3. N'appuyez sur le bouton Novo que si votre modèle en possède un et suivez son manuel.
💻

Acer

Ordinateurs portables et de bureau Acer.

  • BIOS : F2
  • Boot Menu : F12 sur certains modèles
Étapes
  1. Essayez F2 au démarrage pour le BIOS.
  2. Si F12 ne fonctionne pas, vérifiez le manuel du modèle.
💻

ASUS

PC portables et de bureau ASUS.

  • BIOS : F2 sur de nombreux portables
  • Boot Menu : Échap (Esc) sur de nombreux modèles
Étapes
  1. Essayez F2 pour le BIOS ou Échap pour le menu de démarrage.
  2. Les touches peuvent varier selon le modèle exact.
⚙️

MSI / Gigabyte et cartes mères

Sur de nombreux PC de bureau, les touches sont Del ou F2.

  • BIOS : Suppr (Del) ou F2 selon le modèle
  • Boot Menu : souvent F11 ou F12 selon le modèle
Étapes
  1. Consultez le manuel de la carte mère.
  2. Appuyez sur la touche indiquée dès l'allumage.
🧰

Samsung / Toshiba / autres

Les touches diffèrent selon les séries et les générations.

Essayez les touches courantes uniquement si elles correspondent à votre modèle.

Conseils
  • Recherchez le manuel officiel avec le numéro de modèle.
  • Ne supposez pas qu'une même touche fonctionne sur toutes les séries.

3. Démarrer sur une clé USB

  1. Préparez une clé USB d'installation valide. La préparation peut effacer son contenu.
  2. Branchez la clé USB avant d'allumer ou de redémarrer le PC.
  3. Ouvrez le Boot Menu avec la touche correspondant à votre modèle.
  4. Sélectionnez l'entrée USB correspondant à votre clé.
  5. Suivez les instructions à l'écran. Vérifiez soigneusement le disque sélectionné avant toute installation.

Si la clé n'apparaît pas, essayez un autre port USB, vérifiez que la clé est réellement amorçable et consultez les instructions du fabricant. Ne changez pas au hasard les options Secure Boot ou UEFI.

4. Problèmes fréquents et solutions

🚫

No Bootable Device

Le PC ne trouve aucun système de démarrage utilisable.

Solutions à vérifier
  • Vérifiez si le HDD/SSD est détecté dans le BIOS.
  • Vérifiez l'ordre de démarrage.
  • Si le disque est absent, recherchez d'abord une panne matérielle.
💽

HDD / SSD non détecté

Le disque n'apparaît pas dans le BIOS.

Vérifications
  • Éteignez le PC avant toute vérification interne.
  • Sur un PC de bureau, faites vérifier les câbles SATA et d'alimentation.
  • Ne formatez pas un disque contenant des données à récupérer.
🔐

Mot de passe BIOS / BitLocker

Un mot de passe ou une clé de récupération est demandé.

Que faire ?
  • Contactez le propriétaire ou le support officiel du fabricant.
  • Pour BitLocker, recherchez la clé de récupération associée au compte concerné.
  • Ne réinitialisez pas l'appareil sans comprendre les risques de perte de données.
