📘 Structure de Base d’un Ordinateur

1. Schéma Fonctionnel d’un Ordinateur

📥 Entrée → 🧠 Traitement → 📤 Sortie

FR : L’ordinateur fonctionne comme un système de traitement d’information. ML : Ny ordinateur dia mandray (entrée), manodina (traitement), ary mamoaka (sortie).

  • Entrée : clavier, souris
  • Traitement : unité centrale (CPU)
  • Sortie : écran, imprimante

2. Les éléments de l’unité centrale

CPU (Processeur)
FR : cerveau de l’ordinateur ML : ati-doha mibaiko ny asa rehetra
RAM (Mémoire vive)
FR : mémoire temporaire ML : fitadidiana vetivety
Disque dur / SSD
FR : stockage permanent ML : fitahirizana maharitra
Carte mère
FR : relie tous les composants ML : mampifandray ireo singa rehetra

3. Types d’ordinateur

  • 💻 Ordinateur portable (Laptop)
  • 🖥️ Ordinateur de bureau (Desktop)
  • 📱 Tablette
  • 🏢 Serveur

ML : Samy manana ny fampiasana azy ireo karazana ireo.

4. Branchement de la machine

  • 🔌 Câble alimentation
  • 🖥️ Écran → unité centrale
  • ⌨️ Clavier & souris (USB)
  • 🌐 Câble réseau (Internet)

ML : Tokony atao tsara ny fifandraisana rehetra vao mandeha ny machine.

5. Les Ports

USB : clavier, souris, clé USB
HDMI / VGA : écran
Audio : casque, haut-parleur
RJ45 : Internet

6. Manipulation des périphériques

  • 🖱️ Souris : cliquer, déplacer
  • ⌨️ Clavier : écrire
  • 🖨️ Imprimante : imprimer
  • 🔊 Haut-parleur : son

⚠️ ML : Tandremo tsara ny fitaovana (aza kapohina, aza asiana rano, esory tsara amin'ny USB)

5. Les Ports de l’Ordinateur (Détaillé)

FR : Les ports permettent de connecter différents périphériques à l’ordinateur. ML : Ny ports dia toerana fampifandraisana fitaovana amin’ny ordinateur.

🔵 Port USB

Couleur : Noir, Bleu (USB 3.0), Rouge

  • Clavier
  • Souris
  • Clé USB
  • Téléphone

ML : Ity no port be mpampiasa indrindra.

🟣 Port HDMI

Couleur : Noir

  • Écran
  • Télévision
  • Projecteur

ML : Mandefa sary sy feo miaraka.

🔷 Port VGA

Couleur : Bleu

  • Ancien écran

ML : Port taloha, mbola ampiasaina amin’ny écran ancien.

🟢 Port Audio

Couleur :

  • Vert : Haut-parleur
  • Rose : Micro
  • Bleu : Entrée audio

ML : Ampiasaina amin’ny feo.

🟡 Port RJ45 (Internet)

Couleur : Jaune / Transparent

  • Connexion Internet
  • Réseau

ML : Ampifandraisana amin’ny internet câble.
